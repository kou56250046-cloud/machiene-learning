# ML Lab — 体験型 機械学習・パターン認識 実践システム

スライダを動かすと決定境界・損失曲面・クラスタが**その場で変わる**、触って学ぶための
ローカル完結型ダッシュボードです。完全無料・個人運用・サーバー不要。

## 起動

**ワンクリックで起動する場合**（Windows）

`scripts/ML Lab を起動.bat` をダブルクリックします。
デスクトップに置いておくと便利です。ブラウザが自動で開きます。
終了するときは、開いた黒い画面を閉じてください。

プロジェクトを別の場所へ移した場合は、`.bat` の `PROJECT=` を書き換えてください。

**コマンドから起動する場合**

```powershell
uv sync
uv run streamlit run app/Home.py
```

→ http://localhost:8501

> **公開 URL では動きません。** Streamlit は Python のサーバープロセスが必要なので、
> GitHub Pages のような静的ホスティングでは配信できません。ブラウザから URL で
> 開けるようにしたい場合は Streamlit Community Cloud を使う手がありますが、
> 無料枠は RAM 1GB で、このアプリの依存（LightGBM・SHAP・scikit-image ほか）には
> 手狭です。

## データ基盤（Phase 2）

**データカタログ**ページで、公開データを取り込んで Parquet に溜め、DuckDB で SQL を打てます。
サーバーは 1 つも立てません。

| 取得元 | 種類 | APIキー | 内容 |
|---|---|---|---|
| 公開データセット | テーブル | 不要 | iris / wine / 乳がん / 糖尿病 / digits / 住宅価格 |
| 気象データ | 時系列 | 不要 | Open-Meteo。全国 7 都市の日次気温・降水量ほか（1940 年以降） |
| 株価・指数 | 時系列 | 不要 | Yahoo Finance。日経平均・個別株・為替の日次 OHLCV |
| ニュース記事 | テキスト | 不要 | NHK / ITmedia / はてブの RSS。取得のたびに蓄積 |
| 政府統計 e-Stat | テーブル | **要** | 統計表 ID 指定で取得。コードは日本語ラベルに変換済み |

- 保存は `data/raw/<name>.parquet` ＋ 取得条件を残す `<name>.meta.json`
- SQL は読み取り専用（`SELECT` / `WITH` の 1 文のみ）
- 取得したデータは git 管理外。**取り直せるものはリポジトリに入れない**方針

e-Stat のみ無料の利用登録が必要です。取得した appId は `.env.local` に
`ESTAT_APP_ID=...` と書いてください（`.gitignore` 済み）。

## 業務シミュレーション（Phase 9）

ラボ 11 までは「予測が当たっているか」で評価していました。**ラボ 12 からは円で評価します。**

| # | ラボ | 体感できること |
|---|---|---|
| 12 | 在庫・発注 | 1 個余った損と足りなかった損が違うとき、**RMSE 最小の予測は利益を最大にしない**こと |

需要予測 → 発注量の決定 → 1 年ぶんの損益、までを時間を進めながら回します。

- **方策**（予測を発注量に変える規則）を 4 つ並べて比較 — 固定量 / 平均予測 / 安全在庫 / 分位点
- 狙うべきは平均ではなく、臨界比 `CR = Cu/(Cu+Co)` に対応する**分位点**。
  LightGBM の `objective="quantile"` で直接学習します
- 真の需要を知る**オラクル**を並走させ、差を *予測のせいの損* と *決め方のせいの損* に分解。
  **次にモデルを磨くべきか、発注ルールを直すべきか**が数字で決まります
- 「精度と利益の関係」タブで、予測手法 × 方策を総当たり。
  **同じ RMSE でも方策次第で利益が何割も変わる**ことが散布図に出ます

世界は合成データです。実データでは「もし違う判断をしていたら」が測れないため、
上限（オラクル）を計算するには生成の仕組みを自分で決める必要があります。

## 実験ログ

各ラボの下部にある「この結果を記録する」から、設定と結果が
`data/experiments/runs.parquet` に溜まります。**実験ログ**のページで、
試行の推移・どの設定が効いたか・最良の設定を横断して比べられます。

MLflow は採用していません（pandas を 2.x に下げてしまうため。詳細は
アプリ内の解説を参照）。既存の Parquet 基盤に乗せ、サーバーは立てない方針を通しています。

## 構成

```
app/
  Home.py           エントリ（ページ登録）
  views/            各ラボ・データカタログ
  components/       共通 UI 部品（カード・解説・入力欄）
  assets/style.css  ダッシュボードの CSS
mllab/
  data/toy.py       合成データ生成
  data/store.py     Parquet 保存 + DuckDB 検索
  data/connectors/  外部データ取得元
  viz/              配色・決定境界・損失曲面
  models/           モデル定義・クラスタリング
  sim/              業務シミュレーション（世界・方策・損益）
content/            各ページの解説 Markdown
tests/              ユニットテスト + 全ページのスモークテスト
data/               取得データの置き場（git 管理外）
```

計算は `mllab/` に集約し、`app/views/*.py` は UI の組み立てのみ。
ノートブックや CLI からも同じロジックを再利用できます。

## 開発

```powershell
uv run pytest -q          # 通常のテスト（通信しない）
uv run pytest -m network  # 外部 API に実際に繋ぐテスト
```

外部サービスが落ちていてもテストが赤くならないよう、通信はモックしています。

## 今後

データ収集から解析まで、テーブル・時系列・テキスト・画像の 4 領域が一通り揃い、
その先の「意思決定と損益」もラボ 12 で扱えるようになりました。

この先に進むなら：

- **シナリオを増やす** — 見込み客・解約防止（制約下の選択）、予約のオーバーブッキング（確率の校正）、
  与信・保険料率（裾の重い分布・承認バイアス）。`mllab/sim/` の骨組みにそのまま乗ります
- **レシピ（組み合わせ）** — 前処理からモデルまでをブロックで組み、
  1 つ外したときの寄与を**円で**測る
- **CNN / 単語埋め込み** — ラボ 11 の畳み込み、ラボ 10 の TF-IDF の続き。
  学習には GPU が要るので Google Colab の無料枠へ
- **モデルの保存** — 実験ログは設定と結果だけを残しています。
  学習済みモデルそのものを保存する仕組みは未実装です
