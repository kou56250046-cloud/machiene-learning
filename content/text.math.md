## 文書をベクトルにする

文書 `d` を、語彙 `V` の各語の出現回数で表したものが Bag of Words です。

```math
d \;\longmapsto\; \bigl(\mathrm{tf}(t_1, d),\, \mathrm{tf}(t_2, d),\, \dots,\, \mathrm{tf}(t_{|V|}, d)\bigr)
```

語順を捨てるので「犬が人を噛む」と「人が犬を噛む」は同じベクトルになります。**それでも多くのタスクで十分機能する** というのが、この単純化が生き残っている理由です。

## TF-IDF

頻度をそのまま使うと「する」「こと」のような語が上位を独占します。そこで **多くの文書に出る語ほど価値を下げます**。

```math
\mathrm{idf}(t) = \log\frac{1 + n}{1 + \mathrm{df}(t)} + 1, \qquad
\mathrm{tfidf}(t, d) = \mathrm{tf}(t, d)\cdot \mathrm{idf}(t)
```

`n` は総文書数、`df(t)` は語 `t` を含む文書数（式は scikit-learn の既定 `smooth_idf=True` の形）。

- **全文書に出る語** — `df = n` なので `idf ≈ 1`。ほぼ頻度そのまま、相対的に埋もれます。
- **1 文書にしか出ない語** — `idf` が大きくなり、強く持ち上がります。

最後に文書ごとに L2 正規化します。

```math
\tilde{x}_d = \frac{x_d}{\lVert x_d \rVert_2}
```

**長い文書ほど値が大きい、という不公平を消す** ための操作です。これにより内積がそのままコサイン類似度になります。

```math
\cos(d_1, d_2) = \frac{x_{d_1}^{\top}x_{d_2}}{\lVert x_{d_1}\rVert\,\lVert x_{d_2}\rVert} = \tilde{x}_{d_1}^{\top}\tilde{x}_{d_2}
```

**文書の「近さ」を測るとき、ユークリッド距離ではなくコサインを使う** のが定石なのは、長さではなく語の構成比を比べたいからです。

## 共起の強さ — PMI

「一緒に出やすい語のペア」を単純な共起回数で測ると、頻出語のペアばかりが上位に来ます。相互情報量なら、**偶然の同時出現より何倍多いか** を測れます。

```math
\mathrm{PMI}(a, b) = \log\frac{P(a, b)}{P(a)\,P(b)}
```

`PMI > 0` は「偶然より一緒に出る」。負の値を 0 で切った PPMI がよく使われます。単語埋め込み（word2vec）が学習しているものも、理論的には PPMI 行列の低ランク近似であることが知られています。

## トピックモデル

**NMF** は、文書 × 語の行列を 2 つの非負行列に分解します。

```math
X \;\approx\; W H, \qquad W \ge 0,\; H \ge 0
```

`X` が `n × |V|`、`W` が `n × K`（文書ごとのトピック強度）、`H` が `K × |V|`（トピックごとの語の重み）。**非負という制約が「部分の足し合わせ」を強制する** ため、トピックが人の読める形になります（PCA だと負の重みが出て解釈しづらい）。

**LDA** は同じことを確率モデルで書いたものです。

```math
\theta_d \sim \mathrm{Dir}(\alpha), \quad
z_{d,i} \sim \mathrm{Cat}(\theta_d), \quad
w_{d,i} \sim \mathrm{Cat}(\phi_{z_{d,i}}), \quad
\phi_k \sim \mathrm{Dir}(\beta)
```

「文書ごとに話題の配合比 `θ` を引き、語ごとに話題 `z` を選び、その話題の語彙分布から語を出す」という生成の物語です。観測された語から `θ, φ` を逆算します。`α` を小さくすると 1 文書が少数の話題に偏り、大きくすると混ざります。

## 分類 — ベクトルにしたあとは普通の問題

TF-IDF 行列に対する線形分類器は、結局こう書けます。

```math
f(d) = \sum_{t \in d} w_t \cdot \mathrm{tfidf}(t, d) + b
```

**係数 `w_t` がそのまま「その語がどちらのクラスを支持するか」** になるので、根拠を語の一覧として提示できます。次元は数万ですが、1 文書あたりの非ゼロ要素は数十なので、疎行列として扱えば計算は軽く済みます。

多項ナイーブベイズなら、さらに単純に数え上げだけです。

```math
P(t \mid c) = \frac{N_{tc} + \alpha}{\sum_{t'} N_{t'c} + \alpha|V|}
```

`α`（ラプラス平滑化）は、**訓練データに出なかった語の確率が 0 になって全体を潰すのを防ぐ** ための下駄です。
