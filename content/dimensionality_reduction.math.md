## PCA — 分散が最大の向きを固有ベクトルとして解く

まずデータの平均を引き（中心化）、共分散行列を作ります。

```math
\Sigma = \frac{1}{n} X_c^{\top} X_c \quad (d \times d \text{ 行列})
```

「単位ベクトル `u` の向きに射影したときの分散」は `uᵀΣu` です。これを `‖u‖ = 1` のもとで最大化する問題は、ラグランジュの未定乗数法で書けます。

```math
\max_{u} \; u^{\top}\Sigma u - \lambda\bigl(u^{\top}u - 1\bigr)
\;\Longrightarrow\;
\Sigma u = \lambda u
```

**答えは固有ベクトル方程式そのもの** です。第 1 主成分は最大固有値 `λ₁` の固有ベクトル、第 2 主成分は次に大きい `λ₂` の固有ベクトル（互いに直交します）。そして固有値 `λ_k` は、**その軸方向の分散そのもの** です。

```math
\text{寄与率}_k = \frac{\lambda_k}{\sum_{j=1}^{d}\lambda_j}
```

画面の寄与率グラフは、この式を並べたものです。

## 圧縮と復元

上位 `K` 本の主成分だけを使って座標を取り直し（`z = Uᴷᵀ(x - μ)`）、逆に戻すと近似が得られます。

```math
\hat{x} = \mu + \sum_{k=1}^{K} z_k u_k, \qquad
\frac{1}{n}\sum_i \lVert x_i - \hat{x}_i \rVert^{2} = \sum_{j > K} \lambda_j
```

**捨てた固有値の和が、そのまま復元誤差になります。** 「累積寄与率 95% で足りる」という判断は、「誤差を全分散の 5% に抑える」と同じ意味です。

実装では共分散行列を作らず、特異値分解を使います（数値的に安定で速い）。

```math
X_c = U S V^{\top}, \qquad \lambda_k = \frac{s_k^{2}}{n}
```

`V` の列が主成分です。ページ下部に画像として並べた PC1〜PC8 は、この `V` の列を 8×8 に戻したものです。

## t-SNE — 近さを確率にして KL を下げる

元の空間では、点 `i` から見た点 `j` の近さをガウス分布で表します。

```math
p_{j|i} = \frac{\exp\bigl(-\lVert x_i - x_j \rVert^{2} / 2\sigma_i^{2}\bigr)}{\sum_{k \ne i}\exp\bigl(-\lVert x_i - x_k \rVert^{2} / 2\sigma_i^{2}\bigr)}
```

`σ_i` は点ごとに決まり、**perplexity** が指定した「有効な近傍の数」になるよう二分探索されます。

```math
\mathrm{Perp}(P_i) = 2^{H(P_i)}, \qquad H(P_i) = -\sum_j p_{j|i}\log_2 p_{j|i}
```

`perplexity = 30` は「およそ 30 点を近傍とみなす」設定です。**この値で `σ_i` が変わり、絵が激変します。**

地図の上（2 次元）では、裾の重い t 分布（自由度 1）を使います。

```math
q_{ij} = \frac{\bigl(1 + \lVert y_i - y_j \rVert^{2}\bigr)^{-1}}{\sum_{k \ne l}\bigl(1 + \lVert y_k - y_l \rVert^{2}\bigr)^{-1}}
```

そして 2 つの分布の差（KL ダイバージェンス）を勾配降下法で下げます。

```math
\mathrm{KL}(P \Vert Q) = \sum_{i \ne j} p_{ij} \log \frac{p_{ij}}{q_{ij}}
```

## 「島の距離に意味がない」ことの根拠

KL の中身を見ると、非対称性がはっきりします。

- `p_ij` が大きい（元で近い）のに `q_ij` が小さい（地図で遠い）→ **大きな罰**。
- `p_ij` が小さい（元で遠い）のに `q_ij` が大きい → `p_ij` が係数なので **罰はほとんどゼロ**。

つまり損失関数は「近いものを近くに置くこと」だけを要求し、**遠いものをどこに置くかは事実上自由** です。島と島の間隔に意味がないのは、目的関数がそれを一度も評価していないからです。

また t 分布の裾が重いことで、地図上で少し離れた点への反発力が弱くなり、島どうしがはっきり分かれて見えます。**分離の鮮やかさは、部分的には可視化上の演出** だと理解しておくのが安全です。

## 2 つの手法の性質

| | PCA | t-SNE |
|---|---|---|
| 目的関数 | 分散最大（＝復元誤差最小） | 近傍構造の KL 最小 |
| 解 | 固有値問題。**一意** | 勾配降下。初期値依存で **毎回変わる** |
| 新しい点 | `Uᵀ(x-μ)` で射影できる | できない（全体を再計算） |
| 大域構造 | 保つ | 保たない |
| 計算量 | `O(nd²)` 程度 | `O(n²)`（Barnes-Hut で `O(n log n)`） |
