## すべては 4 つの数から出る

混同行列の `TP, FP, FN, TN` だけで、以下がすべて定義されます。

```math
\mathrm{Accuracy} = \frac{TP + TN}{TP + FP + FN + TN}, \qquad
\mathrm{Precision} = \frac{TP}{TP + FP}, \qquad
\mathrm{Recall} = \frac{TP}{TP + FN}
```

分母に注目してください。**適合率の分母は「陽性と予測した数」、再現率の分母は「本当に陽性だった数」** です。同じ `TP` を、違うもので割っている — それだけの違いです。

```math
F_1 = \frac{2 \cdot \mathrm{Precision} \cdot \mathrm{Recall}}{\mathrm{Precision} + \mathrm{Recall}}, \qquad
F_\beta = (1 + \beta^{2})\,\frac{\mathrm{Precision} \cdot \mathrm{Recall}}{\beta^{2}\,\mathrm{Precision} + \mathrm{Recall}}
```

調和平均なので、**片方が 0 に近づくと `F₁` も 0 に落ちます**（算術平均ならごまかせます）。`β > 1` は再現率を重く、`β < 1` は適合率を重く見る設定です。医療スクリーニングでは `F₂` がよく使われます。

## 「精度 98% の罠」を式で見る

陽性の割合（有病率）を `π` とすると、正解率は次のように分解できます。

```math
\mathrm{Accuracy} = \pi \cdot \mathrm{TPR} + (1-\pi)\cdot(1 - \mathrm{FPR}),
\qquad \pi = @pi:\pi@
```

`π = 0.02` のとき、何も検出しないモデル（`TPR = 0`, `FPR = 0`）でも `Accuracy = 0.98`。**第 2 項だけで 98% を稼げてしまう** ことが式から読めます。正解率が使えるのは `π` が 0.5 付近のときだけです。

さらに重要なのが、陽性と言われた人が本当に陽性である確率（適合率＝ PPV）です。ベイズの定理から、

```math
\mathrm{PPV} = \frac{\pi \cdot \mathrm{TPR}}{\pi \cdot \mathrm{TPR} + (1 - \pi)\cdot \mathrm{FPR}}
```

**感度 99%・特異度 99% という優秀な検査でも、`π = 0.001` なら PPV は約 9%** です。陽性と出た 11 人に 1 人しか本当の陽性ではない。モデルの性能は変わっていないのに結論が変わる — 分母に `(1-π)·FPR` が居座るからです。有病率の低い集団に検査を広げてはいけない、という公衆衛生の原則は、この 1 本の式から出ています。

## ROC-AUC の意味

ROC は閾値 `t` を動かしたときの `(FPR(t), TPR(t))` の軌跡です（いまの閾値は @t:t@）。その面積には、順位で読める解釈があります。

```math
\mathrm{AUC} = P\bigl(s(x^{+}) > s(x^{-})\bigr)
```

**無作為に選んだ陽性 1 件と陰性 1 件を比べて、陽性のほうが高いスコアを持つ確率。** 0.5 はコイン投げ、1.0 は完全に順位付けできている状態です。閾値に依存しないので、モデル同士の比較に向きます。

## 不均衡では PR 曲線を見る

`FPR = FP/(FP+TN)` の分母には、大量にある真陰性 `TN` が入っています。陰性が 100 倍あると、`FP` が多少増えても `FPR` はほとんど動きません。**ROC は不均衡データで甘く出る** のはこのためです。

一方 PR 曲線の適合率 `TP/(TP+FP)` に `TN` は現れません。だから陰性を増やしても甘くならない。でたらめなモデルのベースラインも、はっきり `π` になります。

```math
\text{ランダムな分類器の PR ベースライン} = \pi = @pi:\pi@
```

画面の破線がこれです。**PR-AUC は `π` と比べて初めて意味を持ちます**（`π = 0.02` なら PR-AUC 0.3 でも 15 倍の価値がある）。

## 閾値は「コスト」で決まる

見逃し 1 件のコストを `C_FN`、誤報 1 件のコストを `C_FP` とすると、期待コストを最小にする閾値は次の形になります。

```math
t^{*} = \frac{C_{FP}}{C_{FP} + C_{FN}}
```

見逃しが誤報の 9 倍痛いなら `t* = 0.1` — つまり **確率 10% を超えたら陽性と判断すべき** ということ。`0.5` という既定値は「2 つのコストが等しい」という、めったに成り立たない仮定を置いているにすぎません。

## 確率そのものの良さ — キャリブレーション

順位ではなく確率の値を使う場面（期待損失の計算、価格付け）では、Brier スコアで測ります。

```math
\mathrm{Brier} = \frac{1}{n}\sum_{i=1}^{n}\bigl(p_i - y_i\bigr)^{2}
```

**AUC が高くてもキャリブレーションが崩れていることはよくあります**（順位は正しいが、確率が全体的に高すぎる等）。「予測 70% と言った群が、実際に約 70% 陽性か」を確かめるのが信頼度曲線です。

## 交差検証の分散

`K` 分割の平均スコアと、その標準誤差はこう書けます。

```math
\bar{s} = \frac{1}{K}\sum_{k=1}^{K}s_k, \qquad
\mathrm{SE} = \frac{1}{\sqrt{K}}\sqrt{\frac{1}{K-1}\sum_k (s_k - \bar{s})^{2}}
```

**モデル A と B の差が `2·SE` に満たないなら、その差は分割の運の範囲** です。平均だけを比べて優劣を決めるのは、この幅を無視していることになります。
