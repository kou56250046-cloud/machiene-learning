## 更新式はこれだけ

```math
\theta_{t+1} = \theta_t - @eta:\eta@ \, \nabla L(\theta_t)
```

`∇L` は損失を各パラメータで偏微分したベクトル、つまり「いま立っている地点でいちばん急な **上り** の向き」です。マイナスを付けているので、下り方向へ `η`（学習率）の分だけ動きます。画面の矢印 1 本が、この式 1 回ぶんです。

## なぜ下るのか — 1 次の近似

損失をテイラー展開して 1 次で打ち切ると、1 歩ぶんの変化はこうなります。

```math
L(\theta - \eta g) \;\approx\; L(\theta) \;-\; \eta \lVert g \rVert^{2} \;+\; O(\eta^{2})
```

第 2 項は `η > 0` である限り必ず負です。**だから十分に小さい歩幅なら、損失は必ず下がります。** ただしこれは近似で、無視した `O(η²)` の項は `η` の 2 乗で効きます。歩幅を大きくすると、この誤差項が第 2 項の下げ幅を上回ります — これが **発散** の正体です。

## 発散するしきい値

損失が二次形式 `L(θ) = ½ θᵀAθ` のとき、収束する学習率の条件は厳密に書けます。

```math
0 < \eta < \frac{2}{\lambda_{\max}}
```

`λ_max` は地形の最も急な方向の曲率です。**急な谷ほど、許される歩幅は小さい。** 「お椀」で快適な `0.08` が「バナナ谷」で即発散するのは、`λ_max` が桁で違うからです。

さらに、収束の遅さを決めるのは **条件数** です。

```math
\kappa = \frac{\lambda_{\max}}{\lambda_{\min}}
```

細長い谷は `κ` が大きい地形です。学習率は最も急な方向 `λ_max` に合わせるしかないのに、進みたいのは最も緩やかな方向 `λ_min` — だから急な方向で振動しながら、緩やかな方向へじりじりとしか進めません。SGD が谷底を横断できない理由がこれです。

## Momentum — 振動を打ち消す

```math
v_{t+1} = @beta:\beta@ \, v_t + \nabla L(\theta_t), \qquad
\theta_{t+1} = \theta_t - @eta:\eta@ \, v_{t+1}
```

`v` は過去の勾配の指数移動平均です（`β = 0.9` なら直近 10 歩ぶんが混ざります）。

- **振動する方向** — 勾配の符号が毎回入れ替わるので、足し合わせると打ち消し合う。
- **一貫して同じ向きの方向** — 足し合わさって加速する。実効的な歩幅が `1/(1-β)` 倍、`β = 0.9` なら約 10 倍になります。いまの設定なら約 @beta_boost:β 次第@ 倍です。

## RMSProp — 方向ごとに歩幅を変える

```math
s_{t+1} = @rho:\rho@ \, s_t + (1-@rho:\rho@)\, g_t^{2}, \qquad
\theta_{t+1} = \theta_t - \frac{\eta}{\sqrt{s_{t+1}} + \varepsilon} \, g_t
```

`g²` は要素ごとの二乗です。**勾配が大きい方向ほど分母が大きくなり、歩幅が自動で縮みます。** 結果としてすべての方向がほぼ同じ速さで進むようになり、条件数 `κ` の悪さがかなり中和されます。

## Adam — 両方を持つ

```math
m_t = @beta1:\beta_1@ m_{t-1} + (1-@beta1:\beta_1@) g_t, \qquad
v_t = @beta2:\beta_2@ v_{t-1} + (1-@beta2:\beta_2@) g_t^{2}
```

初期値が 0 のため最初の数歩が小さく偏る問題を、割り算で補正します。

```math
\hat{m}_t = \frac{m_t}{1-\beta_1^{\,t}}, \quad
\hat{v}_t = \frac{v_t}{1-\beta_2^{\,t}}, \qquad
\theta_{t+1} = \theta_t - \eta \frac{\hat{m}_t}{\sqrt{\hat{v}_t} + \varepsilon}
```

既定値は `β₁ = 0.9`, `β₂ = 0.999`, `ε = 10⁻⁸`。**何も分からないときの最初の一手** として使われるのは、この補正込みでほとんどの地形に無難だからです。

## 確率的勾配降下法（SGD）の「確率的」

実際には全データで勾配を計算せず、`B` 件のミニバッチで代用します。

```math
\nabla L(\theta) \;\approx\; \frac{1}{B}\sum_{i \in \mathcal{B}} \nabla \ell_i(\theta)
```

これは真の勾配の **不偏推定** で、ばらつきは `1/√B` で減ります。計算が `n/B` 倍速くなる代わりに軌跡がぶれる、という取引です。そしてこのぶれは **鞍点から抜け出す助け** にもなります。勾配がほぼ 0 の地点でも、揺らぎが横方向へ押し出してくれるからです。

## 鞍点と局所解

停留点（`∇L = 0`）の性質は、ヘッセ行列 `H = ∇²L` の固有値で決まります。

| 固有値 | 地形 |
|---|---|
| すべて正 | 局所最小（谷底） |
| すべて負 | 局所最大（山頂） |
| 正と負が混在 | **鞍点** |

パラメータが `d` 個あるとき、固有値がすべて同符号になるのは確率的に稀です。**高次元では停留点のほとんどが鞍点** — 深層学習で「局所解にはまる」心配があまり語られないのは、この事実によります。
