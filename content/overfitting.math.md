## 誤差は 3 つに分解できる

新しいデータに対する二乗誤差の期待値は、必ず次の 3 つの和になります（訓練データの引き方について平均を取った量です）。

```math
\mathbb{E}\Bigl[\bigl(y - \hat{f}(x)\bigr)^{2}\Bigr]
= \underbrace{\bigl(\mathbb{E}[\hat{f}(x)] - f(x)\bigr)^{2}}_{\text{バイアス}^2}
+ \underbrace{\operatorname{Var}\bigl[\hat{f}(x)\bigr]}_{\text{バリアンス}}
+ \underbrace{\sigma^{2}}_{\text{ノイズ}}
```

- **バイアス** — 平均的にどれだけ的を外しているか。次数が低いと大きい。
- **バリアンス** — 訓練データを引き直すたびに予測がどれだけ暴れるか。次数が高いと大きい。
- **ノイズ** — 観測そのものの揺らぎ。**どんなモデルでも消せません**。検証誤差はここより下がりません。

次数を上げるとバイアスが減りバリアンスが増える。この綱引きの結果が、画面の **U 字カーブ** です。U 字の底は「2 つの和が最小になる点」であって、誤差 0 の点ではありません。

## 多項式回帰は線形回帰である

次数 `d` の当てはめは、`x` を `d` 個の列に増やしただけの線形回帰です。

```math
X = \begin{bmatrix} 1 & x_1 & x_1^{2} & \cdots & x_1^{@d:d@} \cr \vdots & & & & \vdots \cr 1 & x_{@n:n@} & x_{@n:n@}^{2} & \cdots & x_{@n:n@}^{@d:d@} \end{bmatrix},
\qquad \hat{w} = (X^{\top}X)^{-1}X^{\top}y
```

`d` を上げると列が増え、`X` の列どうしが強く相関します（`x` と `x²` は似た動きをします）。すると `XᵀX` が **ほとんど逆行列を持たない** 状態になり、係数の解が極端な値へ跳ね上がります。**係数が巨大になるのは計算上の必然** であって、偶然ではありません。

## Ridge — 対角に足して安定させる

```math
\hat{w}_{\text{ridge}} = (X^{\top}X + @alpha_ridge:\alpha@ I)^{-1}X^{\top}y
```

対角に `α` を足すだけで逆行列が安定します。直交する場合の効果は、各係数を一律に縮めることです。

```math
\hat{w}_j = \frac{z_j}{1 + @alpha_ridge:\alpha@}
```

`α → ∞` で係数は 0 に近づきますが、**きっかり 0 にはなりません**。だから Ridge では「0 になった係数」が増えません。

## Lasso — 0 に張り付く理由

罰則を絶対値にすると、解はソフト閾値の形になります。

```math
\hat{w}_j = \operatorname{sign}(z_j)\,\max\bigl(|z_j| - @alpha_lasso:\alpha@,\; 0\bigr)
```

`|z_j| ≤ α` の係数は **きっかり 0** になります。これが特徴量選択そのものです。幾何的にも、L1 の制約領域 `Σ|w_j| ≤ t` は角（軸上の点）を持つ菱形なので、解が軸に触れやすくなります。L2 の制約領域は角のない球なので、軸に触れることはまずありません。

| | 罰則項 | 縮み方 |
|---|---|---|
| Ridge (L2) | `α Σ w_j²` | 全体を比例して縮める |
| Lasso (L1) | `α Σ｜w_j｜` | しきい値以下を 0 にする |

## 正則化は「事前分布」でもある

同じ式をベイズの言葉で書くと、**Ridge は係数に正規分布、Lasso はラプラス分布を事前に仮定した MAP 推定** です。

```math
\hat{w} = \operatorname*{arg\,max}_{w}\; \log p(y \mid X, w) + \log p(w)
```

「係数は 0 の近くにあるはずだ」という信念を数式に足している、というのが正則化の正体です。**罰則の強さ `α` は、その信念の強さ** にあたります。

## データ量との関係

サンプル数 `n`、パラメータ数 `p` としたとき、汎化誤差のズレはおおむね `p/n` のオーダーで効きます。

```math
\text{過学習の危険度} \;\sim\; \frac{p}{n} = \frac{@p:p@}{@n:n@}
```

**`p` を減らす（次数を下げる・正則化する）か、`n` を増やすか。** 対策が原理的にこの 2 択しかないことが、この式から読めます。サンプル数のスライダを下げると U 字の底が左（＝より低い次数）へ動くのは、`p/n` を一定に保とうとする動きです。
