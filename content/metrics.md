## 「精度 98%」の罠

まず **陽性クラスの割合** を `0.02` まで下げてください。100 人に 2 人しか陽性がいない状況です。

このとき「全員に陰性」と答えるだけのモデルは、正解率 98% を叩き出します。何も判定していないのに、です。KPI カードの「正解率」のすぐ下に、その水準を書いてあります。あなたのモデルの正解率がそれを上回っていなければ、モデルには価値がありません。

**不均衡なデータでは正解率は役に立ちません。** これは机上の話ではなく、病気の診断、不正検知、設備故障の予知 — 実務で本当に大事な問題の多くが、まさにこの形をしています。

## 混同行列 — すべての指標の出どころ

閾値スライダを動かすと、4 つのマスの数字が入れ替わります。すべての指標はこの 4 つから計算されます。

| | 予測: 陰性 | 予測: 陽性 |
|---|---|---|
| **実際: 陰性** | 真陰性 (TN) | **偽陽性 (FP)** — 誤報 |
| **実際: 陽性** | **偽陰性 (FN)** — 見逃し | 真陽性 (TP) |

- **適合率 (Precision) = TP / (TP + FP)** — 陽性と言ったうち、本当に陽性だった割合。**誤報の少なさ**。
- **再現率 (Recall) = TP / (TP + FN)** — 本当の陽性のうち拾えた割合。**見逃しの少なさ**。
- **F1** — 上の 2 つの調和平均。片方だけ高くても上がりません。
- **特異度 = TN / (TN + FP)** — 陰性を正しく陰性と言えた割合。

## 適合率と再現率は必ずトレードオフになる

閾値を下げると、モデルは積極的に「陽性」と言うようになります。見逃しは減る（再現率↑）が、誤報が増える（適合率↓）。上げれば逆です。

下段のグラフで、水色（適合率）とピンク（再現率）が逆向きに動くのを確かめてください。**両方を同時に最大にする閾値は存在しません。**

ではどこに置くべきか。それはデータではなく **業務の判断** です。

- がん検診 → 見逃しが致命的。**再現率を優先**（閾値を下げる）
- 迷惑メール判定 → 大事なメールが消えるほうが困る。**適合率を優先**（閾値を上げる）

F1 が最大になる点は「特に事情がなければ」の既定値にすぎません。

## ROC と PR — 閾値に依存しない評価

閾値を決め打ちせずにモデル自体を評価したいときに使うのが、この 2 つの曲線です。

**ROC 曲線** は、閾値をあらゆる値に動かしたときの (偽陽性率, 真陽性率) の軌跡です。左上に張り付くほど良く、その下の面積が **ROC-AUC**。0.5 がでたらめ、1.0 が完璧です。閾値によらないので、モデル同士の比較に向きます。

**PR 曲線** は (再現率, 適合率) の軌跡です。破線が「でたらめなモデル」の水準で、これは陽性の割合そのものです。

**両方を見比べながら陽性割合を 0.5 → 0.05 と下げてみてください。** ROC-AUC はさほど下がらないのに、PR-AUC は大きく落ちます。ROC は真陰性が大量にあると数字が甘く出るためです。**不均衡データでは PR 曲線のほうが正直** です。

## 交差検証 — 1 回の分割を信じない

一番下の帯グラフは、データをどう訓練用（水色）と検証用（ピンク）に分けるかの図です。

1 回だけ分けて測ると、たまたま簡単なテストデータを引いただけかもしれません。何通りにも分け直して平均を取れば、その運を平準化できます。

- **KFold** — 素直に等分する。
- **StratifiedKFold** — 各分割のクラス比を元データと揃える。**不均衡データでは必須**です。そうしないと、陽性が 1 件も入らない分割ができてしまいます。
- **TimeSeriesSplit** — 常に過去で学習し、未来で検証する。時系列データでランダムに分割すると、**未来の情報を使って過去を予測する**ことになり、実際にはあり得ない好成績が出ます（リーク）。

> 分類問題では、迷ったら `StratifiedKFold` を既定にしてください。時系列を扱うなら `TimeSeriesSplit` 以外は選択肢になりません。
