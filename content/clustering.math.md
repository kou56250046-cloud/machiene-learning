## k-means が最小化しているもの

k-means の目的関数は、各点と自分の重心との距離の二乗和（クラスタ内平方和）です。

```math
J = \sum_{k=1}^{K} \sum_{x \in C_k} \lVert x - \mu_k \rVert^{2}
```

アルゴリズムの 2 手順は、この `J` を交互に下げているだけです。

1. **割り当て** — `μ` を固定して `C` を最適化。各点を最も近い重心に入れるのが最小です。
2. **更新** — `C` を固定して `μ` を最適化。`∂J/∂μ_k = 0` を解くと、答えは平均です。

```math
\frac{\partial J}{\partial \mu_k} = -2\sum_{x \in C_k}(x - \mu_k) = 0
\;\Longrightarrow\;
\mu_k = \frac{1}{|C_k|}\sum_{x \in C_k} x
```

**「重心を平均へ動かす」のは思いつきではなく、二乗誤差を最小にする唯一の点だから** です。`J` は各手順で必ず減り、下に有界なので必ず止まります。ただし止まる先は局所最適で、初期値によって変わります（だから `k-means++` が要ります）。

## 丸いかたまりしか作れない理由

点 `x` がクラスタ `k` に入る条件は `‖x-μ_k‖² ≤ ‖x-μ_j‖²`。展開して整理すると、

```math
2(\mu_j - \mu_k)^{\top}x \;\le\; \lVert \mu_j \rVert^{2} - \lVert \mu_k \rVert^{2}
```

**`x` について 1 次式** です。つまりクラスタ間の境界は必ず直線（超平面）になり、できる領域は凸なかたまり（ボロノイ領域）にしかなりません。三日月や同心円は凸ではないので、**原理的に表現できない** ことが式から分かります。

## DBSCAN — 密度で定義する

距離ではなく **近傍に何点あるか** で判定します。

```math
N_\varepsilon(x) = \{\, x' \mid \lVert x - x' \rVert \le \varepsilon \,\}, \qquad
x \text{ がコア点} \iff |N_\varepsilon(x)| \ge \mathrm{minPts}
```

コア点どうしが `ε` でつながっていれば同じクラスタ、どのコア点にも届かない点はノイズ。**この定義には「形」の仮定がない** ので、つながってさえいれば三日月でも渦巻きでも取れます。

`minPts` は次元 `d` に対して `2d` 程度、`ε` は k 距離グラフ（各点の `minPts` 番目に近い点までの距離を並べたもの）の肘から読むのが定石です。

## 階層クラスタリング — Ward 法

併合するたびに、平方和 `J` がどれだけ増えるかを見て、増分が最小のペアを選びます。

```math
\Delta J(A, B) = \frac{|A|\,|B|}{|A| + |B|} \, \lVert \mu_A - \mu_B \rVert^{2}
```

**k-means と同じ量を、逐次的に最小化している** と読めます。だから Ward 法の結果は k-means に似た球状のクラスタになります。連結法（single linkage）に替えると細長い形も取れますが、鎖のようにつながってしまう副作用があります。

## 混合ガウス（GMM）— 確率で書き直す

k-means を「所属が 0/1」から「所属が確率」へ緩めたものです。

```math
p(x) = \sum_{k=1}^{K} \pi_k \, \mathcal{N}(x \mid \mu_k, \Sigma_k), \qquad \sum_k \pi_k = 1
```

E ステップで各点の所属確率（責任度）を計算し、

```math
\gamma_{ik} = \frac{\pi_k \, \mathcal{N}(x_i \mid \mu_k, \Sigma_k)}{\sum_j \pi_j \, \mathcal{N}(x_i \mid \mu_j, \Sigma_j)}
```

M ステップで `π, μ, Σ` を重み付き平均で更新します。**共分散 `Σ_k` を持つぶん、楕円や傾いたかたまりを表現できます。** `Σ_k = σ²I` に固定し、責任度を 0/1 に硬めた極限が k-means です。

## クラスタ数の目安

**エルボー法** — `J(K)` は `K` について単調減少（`K = n` で 0）なので、最小値ではなく **傾きが折れる場所** を探します。

**シルエット係数** — 点 `i` について、`a(i)` は同じクラスタ内の平均距離、`b(i)` は最も近い別クラスタとの平均距離。

```math
s(i) = \frac{b(i) - a(i)}{\max\bigl(a(i),\, b(i)\bigr)} \in [-1, 1]
```

`s(i) < 0` は「隣のクラスタのほうが近い」＝**その点の割り当てが間違っている** ことを意味します。全体平均が 0.5 を超えれば概ね妥当、0.25 を下回るなら構造が見えていない、というのが経験的な目安です。

> どの指標も「幾何的にきれいか」を測っているだけで、**そのクラスタが業務的に意味を持つか** は測れません。最終判断が人間に残る理由です。
