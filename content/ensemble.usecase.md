## どこで使われているか

| 分野 | 課題 | 使われ方 |
|---|---|---|
| 金融 | 与信スコア、不正検知 | GBDT が主力。ロジスティック回帰と併用 |
| 広告・EC | クリック率・購買率の予測 | LightGBM。特徴量数百〜数千 |
| 需要予測 | 販売数、来店客数 | ラグ特徴量 ＋ LightGBM（ラボ 9） |
| 製造 | 歩留まり、異常予知 | ランダムフォレストで重要因子を洗い出す |
| 医療・保険 | リスク層別化 | GBDT ＋ SHAP で根拠を示す |
| 検索・推薦 | 並べ替え | LambdaMART（ランキング用のブースティング） |

**表形式のデータでは、いまも勾配ブースティングが第一選択** です。深層学習が表データで安定して上回る場面は限られており、少ないデータで速く、前処理も少なく済むという実務上の利点が大きいためです。

## ランダムフォレストと GBDT の使い分け

| | ランダムフォレスト | 勾配ブースティング |
|---|---|---|
| 既定値のまま | かなり戦える | 調整しないと本領が出ない |
| 木を増やしすぎたとき | ほぼ悪化しない | **過学習する** |
| 学習速度 | 並列で速い | 直列だが実装が速い（LightGBM） |
| 使いどころ | 初手のベースライン、重要度の把握 | 本番モデル、精度勝負 |

**手順としては、まずランダムフォレストを既定値で回して「このデータでどこまで行けそうか」を掴み、LightGBM で詰める。** これが定石です。差が小さいなら、運用が楽なランダムフォレストのままにする判断もあります。

## LightGBM の実務的な既定値

```python
params = dict(
    n_estimators=2000,        # 多めに置いて early stopping で止める
    learning_rate=0.05,       # 0.01〜0.1。下げたら本数を増やす
    num_leaves=31,            # 増やすと表現力↑・過学習↑
    min_child_samples=20,     # 小さすぎると葉が細分化する
    subsample=0.8,            # 行のサンプリング（相関 ρ を下げる）
    colsample_bytree=0.8,     # 列のサンプリング（同上）
    reg_lambda=1.0,           # 葉の値への L2
)
```

`subsample` と `colsample_bytree` は、**数式編の `ρ` を下げるつまみ** です。ランダムフォレストの発想をブースティングに持ち込んだもので、過学習を抑えつつ精度を保ちます。

## ひとつ具体例を追う

> **クーポン配布の最適化**
> 会員 40 万人、過去の配布ログ 300 万行。「配ったら使うか」を予測する。

1. **ランダムフォレスト**（既定値）— AUC 0.74。重要度の上位に「会員 ID」が来ていて異常に気づく。ID は木にとって都合の良い分岐が作りやすく、**不純度ベースの重要度が過大評価する典型** だった。ID を除外。
2. 除外後 AUC 0.71。下がったが、これが本当の水準。
3. **LightGBM**（`lr=0.05`, early stopping）— AUC 0.78。
4. **Permutation Importance** で確認すると、上位は「直近 30 日の購買回数」「前回クーポン利用有無」「カテゴリ嗜好」。不純度ベースの順位とは 3 位以下が入れ替わっていた。
5. 配布対象を上位 20% に絞り、**配布コストを 1/5 にしたまま利用件数は 82% を維持**。全員配布との比較で ROI が 4 倍。

**モデルの精度そのものより、「上位何%に絞るか」の意思決定に効いた** 例です。評価は Precision@k で見ます（ラボ 6）。

## 落とし穴

- **不純度ベースの重要度を鵜呑みにする。** ID・日時・連続値が不当に上位に来ます。判断に使うなら Permutation Importance か SHAP へ。
- **相関の強い特徴量を並べて重要度を見る。** 重要度が分散して、両方とも低く出ます。
- **木モデルは外挿できない。** 訓練データの範囲外の値には、端の葉の値をそのまま返します。増加トレンドのある時系列にそのまま当てると必ず頭打ちします（ラボ 9）。
- **`n_estimators` を大きくしただけで満足する。** ブースティングは増やしすぎると過学習します。必ず early stopping を併用します。

## このラボで試してほしいこと

1. 木の本数を 1 → 10 → 50 と上げ、**境界がなめらかになると同時に「訓練 − テスト」の差が縮む** ことを見る。アンサンブルの本質は精度より安定性です。
2. 本数を増やし続けて、テスト精度が頭打ちになる点を探す。そこが数式編の `ρσ²` の壁です。
3. ノイズ特徴量を混ぜたタブで、2 種類の重要度の順位が食い違う様子を確認する。**どちらを信じるかで、現場に返す結論が変わります。**
