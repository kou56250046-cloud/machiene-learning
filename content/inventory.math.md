## 新聞売り子問題 — 最適な発注量

需要 `D` は確率変数で、分布関数を `F` とします。`q` 個仕入れたときの損は 2 通りです。

```math
\text{余った損} = C_o \cdot (q - D)^{+}, \qquad
\text{足りない損} = C_u \cdot (D - q)^{+}
```

ここで `(x)⁺ = max(0, x)` です。このラボでは 2 つの費用をこう置いています。

```math
C_u = \underbrace{(p - c)}_{\text{逃した粗利}} + \underbrace{b}_{\text{ペナルティ}} = @Cu:C_u@,
\qquad
C_o = \underbrace{c}_{\text{原価の回収失敗}} + \underbrace{h}_{\text{保管費}} = @Co:C_o@
```

期待損失を最小にする `q` を求めます。

```math
\mathbb{E}[L(q)] = C_o \int_0^q (q-x)f(x)\,dx + C_u \int_q^{\infty} (x-q)f(x)\,dx
```

`q` で微分すると、

```math
\frac{d}{dq}\mathbb{E}[L(q)] = C_o F(q) - C_u\bigl(1 - F(q)\bigr)
```

これを 0 と置けば、**答えは 1 行で出ます。**

```math
F(q^{*}) = \frac{C_u}{C_u + C_o} \;=\; \mathrm{CR} \;=\; @CR:\mathrm{CR}@
\qquad\Longrightarrow\qquad
q^{*} = F^{-1}(\mathrm{CR})
```

**臨界比がそのまま、当てにいくべき分位点になります。** ここが このラボの中心です。

読み取れることが 3 つあります。

1. `Cu = Co` のときだけ `CR = 0.5`、つまり**中央値**が正解。平均を当てにいく手法が正当化されるのは、この特殊な場合だけです
2. `Cu > Co`（欠品のほうが痛い）なら `CR > 0.5` で、平均より多く持つのが正解
3. 最適な発注量 `q*` は、**需要の平均そのものには依存しません。** 依存するのは分布の形と臨界比だけです

## なぜ RMSE 最小の予測が最適でないのか

二乗誤差を最小にする予測は、条件付き期待値、つまり平均です。

```math
\hat{y}_{\mathrm{RMSE}} = \arg\min_{a} \mathbb{E}\bigl[(D - a)^2 \mid x\bigr] = \mathbb{E}[D \mid x]
```

一方、絶対誤差なら中央値になります。

```math
\hat{y}_{\mathrm{MAE}} = \arg\min_{a} \mathbb{E}\bigl[|D - a| \mid x\bigr] = \mathrm{median}(D \mid x)
```

**損失関数を変えると、最適な予測そのものが変わります。** 上の新聞売り子が要求しているのは `CR` 分位点なので、必要な損失関数は次の非対称な形です。

```math
\rho_{\tau}(u) = \begin{cases}
\tau u & (u \ge 0) \\
(\tau - 1) u & (u < 0)
\end{cases}
\qquad \tau = \mathrm{CR} = @CR:\mathrm{CR}@
```

これを **pinball loss（分位点損失）** と呼びます。`τ` が 0.5 なら左右対称になって中央値、0.5 より大きければ**足りない側を重く罰する**ので、予測は上振れします。

```math
\hat{y}_{\tau} = \arg\min_{a}\; \mathbb{E}\bigl[\rho_{\tau}(D - a) \mid x\bigr] = F^{-1}_{D|x}(\tau)
```

LightGBM の `objective="quantile", alpha=@CR:\mathrm{CR}@` がまさにこれです。**欲しい分位点を、平均を経由せずに直接学習します。**

## 分位点を直接出せない手法の場合

線形回帰は平均しか出しません。正規分布を仮定すれば分位点を作れます。

```math
\hat{q} = \hat{\mu} + z_{\tau}\,\hat{\sigma}, \qquad z_{\tau} = \Phi^{-1}(\tau)
```

ただしこれは**需要が正規分布であるという仮定**を挟んでいます。実際の需要は個数なので非負で、裾が右に伸びた形（ポアソン・負の二項）になることが多く、正規近似は裾で外れます。分位点回帰にはこの仮定が要りません。

## 安全在庫 — 教科書の式

リードタイム `L` 日、発注間隔 1 日なら、守るべき期間は `L + 1 = @cover:L+1@` 日ぶんです。この期間の需要が独立なら分散は足し算になるので、標準偏差は `√(L+1)` 倍になります。

```math
S = \hat{\mu}_{L+1} + z\,\hat{\sigma}\sqrt{L+1}, \qquad z = \Phi^{-1}(\text{サービスレベル})
```

**この `z` と、上で導いた `z_τ = Φ⁻¹(CR)` は別物です。** 前者は人が決めた目標、後者はコスト構造から導かれた答え。2 つが一致していない限り、在庫は必ず過剰か過少になります。

サービスレベルを勘で決めるということは、**暗黙のうちに `Cu` と `Co` の比を決めている**ということです。95% を選ぶことは `Cu : Co = 19 : 1` だと宣言するのに等しく、その比が実際の原価と合っているかは誰も確かめていません。

## 発注量 — 在庫ポジションを引く

目標在庫 `S` が決まったら、発注量は差し引きです。

```math
q_t = \bigl(S_t - I_t^{\text{position}}\bigr)^{+},
\qquad
I_t^{\text{position}} = \underbrace{I_t}_{\text{手元在庫}} + \underbrace{\textstyle\sum_{\text{在庫}} q_{t-i}}_{\text{発注残}}
```

**発注残を引き忘れると、リードタイムの間ずっと二重に発注し続けます。** 在庫管理の実装で最も多いミスです。`L = @L:L@` 日のいまは、発注残が @L:L@ 日ぶん積まれています。

## 損益

1 日ぶんの利益は次の 5 項の和です（費用は負）。売れ残りは資産のままで、売れたときか捨てたときに費用へ落とします。

```math
\pi_t = \underbrace{p\,s_t}_{\text{売上}} - \underbrace{c\,s_t}_{\text{売上原価}} - \underbrace{c\,w_t}_{\text{廃棄損}} - \underbrace{h\,I_t}_{\text{保管費}} - \underbrace{b\,u_t}_{\text{欠品損}}
```

`s` は販売数、`w` は廃棄数、`u` は欠品数です。**この 5 項を足すと利益に一致します**（`Ledger.check_closes` がテストで確かめています）。原価を発注時と廃棄時の両方で数える、という二重計上をやると、ここが合わなくなります。

在庫の保存則も同時に成り立ちます。

```math
I_{t-1} + a_t - s_t - w_t = I_t \qquad (a_t = \text{入荷})
```

## 損失の分解

3 つの利益を比べます。`π*` は完全予見、`π̂_best` は同じ予測での最良方策、`π̂` は選んだ方策です。

```math
\underbrace{\pi^{*} - \hat{\pi}}_{\text{オラクルとの差}}
= \underbrace{\bigl(\pi^{*} - \hat{\pi}_{\text{best}}\bigr)}_{\text{予測誤差による損失}}
+ \underbrace{\bigl(\hat{\pi}_{\text{best}} - \hat{\pi}\bigr)}_{\text{方策の非最適性による損失}}
```

右辺の第 1 項が大きければモデルに、第 2 項が大きければ発注ルールに手を入れます。

第 1 項には**原理的に消せない部分**が含まれます。需要のポアソン変動は、どんな特徴量を足しても予測できません。オラクルは到達目標ではなく、**距離を測るための物差し**です。
