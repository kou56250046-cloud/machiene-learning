## 系列を 3 つに分ける

加法モデルでは、観測値を次の 3 つの和と見なします。

```math
y_t = T_t + S_t + R_t
```

トレンド `T`、季節 `S`（周期 `m` で `S_{t+m} ≈ S_t`）、残差 `R`。振れ幅が水準に比例して大きくなる系列では、対数を取って加法に直します。

```math
y_t = T_t \cdot S_t \cdot R_t
\;\Longrightarrow\;
\log y_t = \log T_t + \log S_t + \log R_t
```

**「売上が伸びると季節変動の振れ幅も大きくなる」** タイプの系列で、対数変換が効く理由です。

STL は、移動平均でトレンドを取り、周期ごとに集めた値へ局所回帰（LOESS）を当てて季節を推定する、という操作を反復します。ロバスト版は外れ値の重みを下げるので、**異常値があっても季節成分が壊れません**。

成分の強さは、残差との分散比で定義されます。

```math
F_S = \max\left(0,\; 1 - \frac{\operatorname{Var}(R_t)}{\operatorname{Var}(S_t + R_t)}\right)
```

1 に近いほど季節性が強い。**0.6 を超えたあたりから「季節を使えば当てられる」系列** と考えてよい目安になります。

## 自己相関

ラグ `k` の自己相関は、系列を `k` だけずらした自分自身との相関です。

```math
r_k = \frac{\sum_{t=k+1}^{n}(y_t - \bar{y})(y_{t-k} - \bar{y})}{\sum_{t=1}^{n}(y_t - \bar{y})^{2}}
```

白色雑音なら `r_k` はおよそ `N(0, 1/n)` に従うので、信頼区間は次の幅になります。

```math
\pm \frac{1.96}{\sqrt{n}} \quad (n = @n:n@)
```

**この帯を超えたラグだけが「偶然とは言えない」** — 画面の水色の帯がこれです。日次データで `r_7` が突き出ていれば週周期、`r_365` なら年周期です。

偏自己相関 (PACF) は、途中のラグの影響を取り除いた「純粋な `k` 期前との関係」です。ACF が緩やかに減衰し PACF が `p` で切れるなら AR(`p`)、逆なら MA(`q`) — これが古典的なモデル選択の読み方です。

## 定常性と差分

多くの手法は「平均と分散が時間によらない」ことを前提にします。トレンドがあれば差分で消せます。

```math
\Delta y_t = y_t - y_{t-1}, \qquad
\Delta_m y_t = y_t - y_{t-@m:m@} \;(\text{季節差分})
```

ARIMA(`p,d,q`) の `d` は、この差分を何回取るかです。

## ラグ特徴量 — 時系列を表形式に直す

木モデルに解かせるときは、過去の値を列に並べ替えます。

```math
x_t = \bigl(y_{t-1},\, y_{t-2},\, \dots,\, y_{t-L},\; \overline{y}_{t-1:t-w},\; \text{曜日},\, \text{月},\, \dots\bigr)
```

**重要なのは、`t` 時点の特徴量に `t` 以降の情報を絶対に入れないこと。** 移動平均も `y_t` を含めずに `t-1` までで作ります。これを破ると、検証スコアだけが跳ね上がり本番で崩れます（時系列で最も多い事故です）。

## 評価 — ナイーブ予測との比

```math
\mathrm{MAE} = \frac{1}{n}\sum_t |y_t - \hat{y}_t|, \qquad
\mathrm{RMSE} = \sqrt{\frac{1}{n}\sum_t (y_t - \hat{y}_t)^{2}}
```

RMSE は二乗するぶん **大外し 1 回を重く見ます**。どちらを使うかは、業務で大外しがどれだけ痛いかで決めます。

MAPE は割合で見られますが、`y_t` が 0 付近で発散するという致命的な弱点があります。代わりに **MASE** を使うと、単位に依存せず「前期の値をそのまま予測に使うナイーブ法の何倍良いか」で測れます。

```math
\mathrm{MASE} = \frac{\mathrm{MAE}_{\text{モデル}}}{\frac{1}{n-m}\sum_{t=m+1}^{n}\bigl|y_t - y_{t-m}\bigr|}
\quad (m = @m:m@)
```

**`MASE < 1` で初めて、ナイーブ法に勝った** ということです。1 を超えるモデルには価値がありません。

## 時系列の交差検証

```math
\text{分割 } k: \quad \text{訓練} = y_{1:t_k}, \quad \text{検証} = y_{t_k+1:\,t_k+h}
```

**常に過去で学習し、未来で検証します。** ランダム分割は、未来の値を見てから過去を当てることになり、現実にはあり得ない好成績を出します。`TimeSeriesSplit` がやっているのはこの制約です。
