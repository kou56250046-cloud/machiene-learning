## 何に使われているか

| 分野 | 使い方 | 手法 |
|---|---|---|
| マーケティング | 顧客セグメント（RFM 分析） | k-means / GMM |
| 小売 | 店舗のタイプ分け、棚割りの類型化 | k-means + 階層 |
| 製造・設備 | センサーの異常パターン検出 | DBSCAN（ノイズ＝異常） |
| 画像 | 色の量子化、領域分割 | k-means |
| 文書・問い合わせ | 話題の自動整理（ラボ 10 へ） | k-means / LDA |
| 生物・医療 | 遺伝子発現パターンの分類 | 階層（樹形図で見せる） |
| 地理・物流 | 配送拠点の候補地決定 | k-means（重心＝拠点） |

## 現場での使われ方

**顧客セグメント（RFM）**

最終購入日 (Recency)、購入回数 (Frequency)、購入金額 (Monetary) の 3 列で k-means を回します。出てくるのは例えば次の 4 群です。

| 群 | 特徴 | 打ち手 |
|---|---|---|
| 優良 | 直近・高頻度・高額 | 上位会員特典、離反の早期検知 |
| 休眠予備軍 | 過去は高額、最近は無し | 復帰クーポン |
| 新規 | 直近・低頻度 | 2 回目購入の後押し |
| ライト | 低頻度・低額 | 施策を打たない（費用対効果） |

肝は最後の行です。**「施策を打たない群を決める」ことが、セグメント化の最大の効果** であることが多い。全員に同じクーポンを配る運用から抜けるための道具です。

**配送拠点の決定**

顧客の緯度経度に k-means をかけると、重心がそのまま「そこに倉庫を置けば総移動距離が最小になる点」になります。目的関数が距離の二乗和そのものなので、**問題と手法が完全に一致している** 珍しい例です。

**異常検知としての DBSCAN**

正常なセンサー値は密集し、故障時の値は疎らに散ります。DBSCAN はどのクラスタにも入らない点をノイズ（`-1`）として返すので、**ラベルなしで異常候補を拾う** 仕組みとして使えます。「異常のラベルが 1 件も無い」という、実務で最もよくある状況に効きます。

**色の量子化**

画像の全画素を RGB の 3 次元の点とみなし、`k = 16` で k-means。各画素を自分の重心の色で置き換えれば、16 色に減色されます。GIF の減色処理や、デザインの配色抽出はこれです。

## ひとつ具体例を追う

> **問い合わせ 1 万件の整理**
> テキストを TF-IDF でベクトル化（ラボ 10）、SVD で 50 次元に圧縮（ラボ 5）してから k-means。

1. `k` を 2〜20 で振り、エルボーとシルエットを見る。エルボーは 6 付近、シルエットは 8 が最大。
2. `k = 6` と `k = 8` の両方を出し、**各クラスタの代表的な問い合わせ 5 件を読む**。`k = 8` では「返品」が 2 つに割れており、片方は「サイズ違い」、もう片方は「初期不良」だった。
3. **業務的に打ち手が違うので `k = 8` を採用。** 指標は 6 を、業務は 8 を支持した — この判断は数式からは出ません。
4. 結果を FAQ の章立てに反映し、上位 3 クラスタで全体の 54% を占めることを根拠に、そこから着手した。

## 効果的な条件 / つまずくところ

- **必ずスケーリングする。** 年収（〜1000 万）と年齢（〜100）を混ぜると、距離はほぼ年収だけで決まります。単位を揃えないクラスタリングは、ほぼ意味を持ちません。
- **次元が高いと距離が効かなくなる。** 数百次元では点どうしの距離が均一に近づきます（次元の呪い）。PCA や SVD で数十次元へ落としてから当てるのが定石です。
- **カテゴリ列が多いなら k-means を使わない。** ワンホット後のユークリッド距離は意味が薄くなります。k-modes やガワー距離＋階層法を検討します。
- **クラスタは「発見」ではなく「切り方の提案」。** 同じデータでも手法と `k` で結果は変わります。**業務で説明できる切り方かどうか** が最終的な採否基準です。
