## 分類器は「1 本の関数」でできている

どの分類モデルも、やっていることは同じ形に書けます。入力 `x` に対してスコアを返す関数 `f` を作り、その符号で答えを決める。決定境界とは、そのスコアがちょうど 0 になる場所の集まりです。

```math
\hat{y}(x) = \operatorname{sign} f(x), \qquad
\text{決定境界} = \{\, x \mid f(x) = 0 \,\}
```

**`f` にどんな形の関数を許すか** — モデルの違いはそれだけです。画面に出ている線の形は、この `f` の形がそのまま現れたものです。

## ロジスティック回帰 — 直線しか引けない理由

確率をシグモイド関数で表します。

```math
P(y=1 \mid x) = \sigma(w^{\top}x + b), \qquad
\sigma(z) = \frac{1}{1 + e^{-z}}
```

`σ(z) = 0.5` になるのは `z = 0` のときだけです。つまり境界は次の式で書ける平面（2 次元なら直線）に必ずなります。

```math
w^{\top}x + b = 0
```

**曲げようがない** のはこのためです。学習は、正解の確率を最も高くする `w` を探すこと — 交差エントロピー損失の最小化です。

```math
\min_{w,\,b}\; -\sum_{i=1}^{n}\Bigl[\, y_i \log p_i + (1-y_i)\log(1-p_i) \,\Bigr] \;+\; \frac{1}{2 \cdot @C_logreg:C@}\lVert w \rVert^{2}
```

右端が正則化項です。**`C` は罰則の逆数** なので、`C` を小さくするほど `w` が縮み、境界の傾きがなだらかで安定した直線になります。

## SVM — マージンを最大化する

境界からいちばん近い点までの距離（マージン）は `2 / ‖w‖` です。これを最大にする＝`‖w‖` を最小にする、という問題になります。

```math
\min_{w,\,b}\; \frac{1}{2}\lVert w \rVert^{2}
\;+\; @C_svm:C@ \sum_{i=1}^{n} \max\bigl(0,\; 1 - y_i (w^{\top}x_i + b)\bigr)
```

後半の `max(0, 1 - y·f)` が **ヒンジ損失** です。正しくかつ余裕をもって分類できた点の損失はきっちり 0 になります。だから **境界の決定に効くのはマージン付近の点だけ**（サポートベクタ）で、遠くの点をいくら動かしても線は変わりません。ロジスティック回帰との違いはここです。

## カーネル — 曲げるための仕掛け

RBF カーネルは、2 点の近さを距離の指数関数で測ります。

```math
k(x, x') = \exp\bigl(-@gamma:\gamma@ \lVert x - x' \rVert^{2}\bigr), \qquad
f(x) = \sum_{i \in SV} \alpha_i y_i \, k(x_i, x) + b
```

`f` は「サポートベクタごとの山」を重ね合わせた関数なので、いくらでも曲がります。山の広がりは `1/√γ` 程度で、いまの設定なら @gamma_width:γ 次第@ です。**`γ` を上げると山が細くなり、点の周りに小さな島ができる** — 画面で起きているのはこれです。

## kNN — 学習しない分類器

```math
\hat{y}(x) = \operatorname*{arg\,max}_{c} \sum_{i \in N_{@k:k@}(x)} \mathbf{1}\bigl[y_i = c\bigr]
```

`N_k(x)` は `x` に近い `k` 個の点です。パラメータを一切持たず、境界の形に制約もありません。`k = 1` なら各点の縄張り（ボロノイ図）がそのまま境界になり、ノイズ 1 点が境界を歪めます。

## 決定木 — 階段になる理由

分岐は必ず「1 つの特徴量としきい値」の形 `x_j ≤ t` です。1 本の軸にしか言及しないので、**切り口は必ず軸に平行** — 斜めの境界は階段で近似するしかありません。どこで切るかは不純度の下がり幅で決めます。

```math
G(S) = 1 - \sum_{c} p_c^{2}, \qquad
\Delta G = G(S) - \frac{|S_L|}{|S|}G(S_L) - \frac{|S_R|}{|S|}G(S_R)
```

`ΔG` が最大になる `(j, t)` を全通り試して選ぶ、を再帰的に繰り返します。

## ナイーブベイズ — 二次曲線になる理由

ベイズの定理に「特徴量どうしは独立」という強い仮定を足したものです。

```math
P(y=c \mid x) \;\propto\; P(y=c) \prod_{j=1}^{d} P(x_j \mid y=c)
```

各 `P(x_j | y)` を正規分布とすると、対数を取った判別関数は `x` の **二次式** になります。だから境界は放物線や楕円といった二次曲線として現れます。掛け算と足し算だけで学習が終わるので、桁違いに速いのが特徴です。

> 表の「引ける線の形」は、この節の数式の形をそのまま日本語にしたものです。**モデル選びとは、境界の関数形を選ぶこと** だと分かれば、初めて見るモデルでも性格を推測できるようになります。
